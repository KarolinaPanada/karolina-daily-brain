# karolina-daily-brain

Личный набор Claude Code скиллов для контента канала [@eaudekarolina](https://instagram.com/eaudekarolina) (парфюмерный блог) и связанного видео-продакшна.

## Что внутри

### `.claude/skills/` — скиллы для парфюм-контента

- **`perfume-day-post`** — пишет текстовые посты в рубрике «аромат дня» (Telegram/Instagram) голосом Каролины. Срабатывает на голое название аромата, на фото флакона/коробки или на прямую просьбу написать пост. Структура и голос построены на разборе её реальных постов из канала eaudekarolina (`references/format.md`, `references/voice.md`).
- **`perfume-reel-scripts`** — пишет сценарии для парфюмерных рилзов (Instagram/TikTok): 4 варианта хука, техника интригующей подачи (название аромата раскрывается в конце), фирменные рубрики канала (дюпы, распаковки, день бренда, подборки, ретро). Детальный разбор голоса и техники описания запаха — в `references/style.md`.
- **`remotion-motion-graphics`** — создание и правка motion graphics видео на Remotion (React-based рендер видео): нелинейный easing, многослойные сцены, Ken Burns на статике, готовый theme-объект и обязательная проверка рендера кадр за кадром.

### `.agents/skills/` — сторонние видео-скиллы (Pexo)

Пакет от [`pexoai/pexo-skills`](https://github.com/pexoai/pexo-skills) для AI-генерации видео через API [pexo.ai](https://pexo.ai) (автовыбор модели среди Seedance, Kling, Veo, Sora и др.):

- **`pexo-agent`** — универсальный агент: полный пайплайн от текста/скрипта/изображения/аудио до готового многосюжетного видео с музыкой и субтитрами.
- **`text-to-video`** — генерация видео из текстового промпта или сценария.
- **`explainer-video`** — объясняющее/обучающее видео с закадровым голосом (TTS) и субтитрами по описанию продукта или процесса.

Требуют переменные окружения `PEXO_API_KEY` / `PEXO_BASE_URL` и `curl`/`jq`/`file` в системе. Запросы жёстко закреплены за `pexo.ai` — скрипты отказываются слать credentials на любой другой хост.

`skills-lock.json` в корне — файл-лок этого пакета: фиксирует источник и хэш каждого установленного pexo-скилла.

## История репозитория

Проект начинался как Playwright + TypeScript портфолио по UI/API автоматизации тестирования (POM, fixtures, API-клиент, CI), но тестовый код и лендинг были убраны — сейчас репозиторий используется как хранилище для персональных Claude Code скиллов.
